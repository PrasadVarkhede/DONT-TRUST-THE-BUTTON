## AI Tools Used

 1. ChatGPT — Used

- Brainstormed the original game concept, **Don't Trust the Button**.
- Suggested puzzle mechanics and level ideas.
- Prepared prompts and a step-by-step development workflow for Antigravity.
- Helped plan UI integration, testing, and documentation.

2. Google Antigravity — Used

- Reviewed the proposed `GAME_DESIGN.md` specification and presented design decisions.
- Received instructions to build the playable game, preserve puzzle mechanics, and test levels.
- Received instructions to integrate the UI designs generated by Google Stitch.
- Implementation and testing results must be verified against the actual project before claiming completion.

 3. Google Stitch — Used for UI Design Generation

- Received six design folders:
  - `arcade_mischief`
  - `final_victory_screen`
  - `game_over_retry_screen`
  - `level_complete_screen`
  - `main_menu_level_selection`
  - `puzzle_gameplay_screen`
- These designs are intended for the game's main menu, gameplay, level completion, retry, and final victory screens.
- Integration into the running game is not yet confirmed.

Development Approach

The game is being developed as a browser-based puzzle game with a focus on original mechanics, clear visual clues, fair puzzle solutions, responsive controls, and an offline-capable experience.

The proposed design includes eight original levels earlier but we have added 1 more making of total 9 levels . An additional easy level, **The Sneaky Shadow**, was later proposed. The final level count and implementation must be confirmed in the actual game.
